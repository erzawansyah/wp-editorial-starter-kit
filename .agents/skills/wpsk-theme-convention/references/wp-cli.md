# Generating your theme with WP-CLI

For humans who prefer the command line, and for LLMs that prefer the command line even more

After [installing WP-CLI](https://wp-cli.org/#installing), please run the following command to install _tw&#8217;s WP-CLI package:

`wp package install underscoretw/scaffold`Code language: plaintext (plaintext)Most people will want to use the interactive wizard to generate a theme:

`wp scaffold _tw`Code language: plaintext (plaintext)If you want to generate themes via command-line arguments, you&#8217;ll find all of the details necessary to do so via the `--help` argument:

`wp scaffold _tw --help`Code language: plaintext (plaintext)You&#8217;ll find more details in the [corresponding GitHub repository](https://github.com/underscoretw/scaffold).
